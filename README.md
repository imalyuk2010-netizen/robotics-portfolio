# Robotics Studio — 3D portfolio

```
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in /dist
```

Add your work: put photos in `public/projects/` and set `image: '/projects/yourfile.jpg'`
for each entry in `src/config.js` (also edit your name, bio and email there).
Photos display at 3:2 — crop to 1500×1000 for best results.

Files: `Room.jsx` (the studio), `Robot.jsx` / `Rover.jsx` (animated props),
`Frame.jsx` (photo frames), `CameraRig.jsx` + `layout.js` (camera moves), `UI.jsx` (overlay).
